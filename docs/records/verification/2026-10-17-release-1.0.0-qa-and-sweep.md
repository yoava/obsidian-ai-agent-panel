## Findings

1. **034.3, fail: the active tab shows no close button.** The row and
   PRD-001.R7 ("while the pointer is over a tab or the tab is active") expect
   it; DES-003 (Tab item: "close button on hover only") and the tabs of task
   059, accepted on 2026-10-13, draw it on hover only, so `styles.css` has no
   `is-active` rule. The two current documents disagree; the owner decides
   whether PRD-001.R7 follows the design or a `fix(tabs)` shows the button on
   the active tab. Unchanged in 1.0.0.
2. **038.1, observation: an edit card's sub-line is the folder.** As DES-003
   specifies (Permission card: the title, then the folder and the counts);
   the file is in the title, `Edit note.md?` when the CLI sends no title. The
   harness case had passed a title of its own, "Edit", so its first shot
   showed no file name; the README shot was taken again without it, and the
   row's wording now says what the sub-line shows.
3. **034.4 and 034.9, inconclusive: Shift+F10 and the context-menu key.** A
   synthetic key press raises no `contextmenu` event, which the plugin
   listens to; right-click opened the row menu. The owner's Obsidian run.
4. **034.4, observation: Enter on a column row selects the conversation and
   leaves focus on the body**; on a strip tab it moves to the composer. No
   requirement says where focus goes; for the keyboard pass.
5. **044, observation: one damaged history file logs its warning twice.**
   Console only; the conversation opens. A 1.0.x candidate.
6. **034.6, harness: the close probe timed out after the confirmation
   dialog**; the last-tab step was not reached. The owner's run.
7. **032.4, harness: the red Auto and Bypass segment was not reached**; the
   probe set the default mode only, and a reopened conversation keeps its
   stored mode. The owner's run.
